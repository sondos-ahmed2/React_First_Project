# Solar Explorer
## About The Project
Solar Explorer is a responsive website that allows users to explore the Solar System and discover information about its planets and Users can browse the planets and view detailed information about each planet.
## tech stack
- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Bootstrap 5
- React Router DOM
- Axios
## API Used
https://solar-system-opendata-proxy.vercel.app/api/planets
## components 
- NavBar
- Home
- planets
- planetsDetails
- NotFound
- Footer
## Features
- Explore the planets in the Solar System.
- View detailed information about each planet.
- Display planet images,  Name and descriptions.
- Navigate between pages using React Router.
- Responsive design using Bootstrap.
- Loading spinner while fetching data from the API.
- Not Found page for invalid routes.
